## ⚡ Tech-Stack & Architektur

Die Webseite wurde im Zuge einer Modernisierung vollständig auf den neuesten Stand der Technik gebracht. Der Fokus lag hierbei auf maximaler Performance, semantischem HTML5 und einem barrierefreien, responsiven Design.

- **UI-Framework:** Bulma v1.x (Modernisiertes CSS-Variables-Theming & Smart-Grid-Strukturen)
- **Erweiterungen:** Bulma-Collapsible (Interaktive Akkordeon-Komponenten)
- **Typografie:** Inter & JetBrains Mono (Optimierter Tech- & Application-Look)
- **Performance:** CSS-Minifizierung für optimierte Ladezeiten und hervorragende Core Web Vitals
- **Icons:** Material Design Icons (MDI)

## 🚀 Mein technologisches Leuchtturm-Projekt (2026)

Das Herzstück meiner aktuellen Arbeit ist die **Stock Analysis Plattform**, eine komplexe und containerisierte Enterprise-Anwendung. Ich verbinde darin modernste Microservice-Architekturen mit datengetriebenem Machine Learning.

👉 **[Hier geht es direkt zum Source-Code des Börsenprojekts](https://github.com)**

### Core-Highlights des Projekts:

- **Distributed Architecture:** Verteilte Services auf Basis von Java 25, Spring Boot 4.1 und Python (FastAPI).
- **Predictive Intelligence:** ML-Service mit einem XGBoost-Modell zur Errechnung von Reversal-Signalen samt automatisiertem wöchentlichen Retraining.
- **Real-Time Data:** Reaktives Angular-Frontend mit Datenstreaming via Server-Sent Events (SSE).
- **Security & Env:** Abgesichert über ein Gluetun VPN Gateway mit TLS-Fingerprinting, konsistente Datenhaltung via Flyway in MySQL, vollständig Docker-containerisiert.
