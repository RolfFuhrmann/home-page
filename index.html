Aktuelles Projekt

Stock Analysis Plattform

Code auf GitHub ansehen

Ein anspruchsvolles Open-Source-Projekt, mit dem ich eine containerisierte Microservice-Architektur, reaktive Webentwicklung, automatisierte Datenverarbeitung und Machine Learning praktisch im Jahr 2026 verbinde.

MICROSERVICE ARCHITECTURE & INTEGRATION

Von der Vision zur lauffähigen, verteilten Cloud-Anwendung.

Die Plattform verbindet ein reaktives Angular-Frontend via Server-Sent Events (SSE) mit spezialisierten Backends. Kursdaten werden über Yahoo Finance und Twelve Data bezogen. Ein hochgradig optimierter Agent steuert die Datenströme, während ein separater ML-Service auf Basis von 38 technischen Features ein prädiktives, XGBoost-basiertes Reversal-Signal errechnet.

Zum Schutz vor Anti-Scraping-Mechanismen läuft das System isoliert hinter einem Gluetun VPN Gateway mit dynamischer IP-Rotation und TLS-Browser-Fingerprinting. Die Datenhaltung erfolgt konsistent in einer MySQL-Datenbank mittels automatisierter Flyway-Migrationen. Der gesamte Workflow von der Analyse bis zum automatisierten wöchentlichen Modell-Retraining wird hocheffizient durch den gezielten Einsatz von KI-Werkzeugen unterstützt.

Hinweis: Das Projekt dient der technischen und analytischen Auseinandersetzung mit Börsendaten und stellt keine Anlageberatung dar.

Architektur & Datenfluss

Frontend: Angular Client (SSE & Real-Time UI)
Processing & Core: Agent Service (Python & Java/Spring Boot 4.1 port)
Data Protection: Gluetun VPN Gateway & curl_cffi Browser-Faking
Intelligence & Prediction: ML Service (Python, FastAPI & XGBoost Model)
Storage & Versioning: MySQL 9.7 & Flyway Database Migrations

Eingesetzte Technologien & Plattformen:

Angular Java 25 / Spring Boot 4.1 Python / FastAPI XGBoost / Machine Learning MySQL / Flyway Docker / Gluetun VPN SSE (Server-Sent Events) GitHub Open Source

Über Mich

Softwareentwicklung ist für mich nicht nur ein Beruf, sondern eine echte Leidenschaft. Seit meinem Informatikstudium sammele ich kontinuierlich branchenübergreifende Erfahrungen in der Entwicklung komplexer Systeme – für IT-Dienstleister, Industrie, Banken und das Versicherungswesen. Diese tiefe Projekterfahrung ermöglicht es mir, mich extrem schnell in bestehende Architekturen einzufinden und Verantwortung zu übernehmen.

Warum ich heute den Unterschied mache: Während viele sich auf bewährten Pfaden ausruhen, treibt mich meine Neugierde mitten in die technologische Zukunft. Seit Anfang des Jahres widme ich mich intensiv dem Bau moderner Microservice-Plattformen und der Integration von Machine Learning. Durch den täglichen, praktischen Einsatz von KI-Werkzeugen in meinen aktuellen Open-Source-Projekten auf GitHub habe ich meinen Entwicklungs-Workflow massiv beschleunigt und optimiert.

Mein Arbeitsstil ist absolut zielorientiert, verlässlich und von hoher Teamfähigkeit geprägt. Ich behalte auch in kritischen Projektphasen einen kühlen Kopf. Gerade in Zeiten, in denen Projekte schnell und präzise realisiert werden müssen, unterstütze ich Unternehmen flexibel und tatkräftig als erfahrener Fullstack-Entwickler.

Ich suche die Zusammenarbeit mit Unternehmen, die diese seltene Kombination aus krisenerprobter Senior-Expertise, hoher Eigenmotivation und modernstem Tech-Know-how wertschätzen. Lassen Sie uns anspruchsvolle Herausforderungen gemeinsam meistern – ich freue mich auf Ihr Projekt.
